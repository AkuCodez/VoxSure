# Recording script (optional): measure real speech accuracy

Record yourself reading each sentence once, in a quiet room, at normal speed. Save each clip as `<lang>_<number>.wav` (or .m4a/.mp3), e.g. `hi_01.wav`, into a folder `D:\VoxSure\ml\human_audio\`. 10 clips per language is enough for a first measurement.
Windows: open the **Voice Recorder** app, record, then Share/Save As. Tell the assistant when the folder is ready; the evaluation script for human clips still has to be written.

Note: the sentences below were written by the project author, not verified by native speakers. If any sentence sounds unnatural to you, say it your own way and tell me what you said.
